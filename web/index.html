💡 Hướng dẫn tạo file .bin từ Arduino IDE:
  1. Mở miu_eilik.ino trong Arduino IDE.
  2. Chọn đúng bo mạch ESP32S3 Dev Module (Flash: 16MB, PSRAM: OPI).
  3. Nhấn menu Sketch → Export Compiled Binary (hoặc phím tắt Ctrl + Alt + S).
  4. File miu_eilik.ino.bin sẽ xuất hiện trong thư mục dự án để bạn nạp ngay!
