STEP-BY-STEP GUIDE

Hướng Dẫn Nạp & Vận Hành

Các bước đơn giản để nạp code và kiểm tra Robot MIU Eilik trực tiếp qua trình duyệt máy tính.

01
Kết nối Cáp Type-C
Cắm cáp Type-C có chức năng truyền dữ liệu vào cổng USB của bo mạch ESP32-S3.
02
Mở Trình Duyệt Chrome/Edge
Đảm bảo dùng Chrome hoặc Edge phiên bản 89+ trên máy tính để hỗ trợ Web Serial API.
03
Bấm "KẾT NỐI CỔNG SERIAL"
Chọn cổng COM của ESP32-S3 từ bảng hiển thị. Đèn trạng thái sẽ chuyển sang màu xanh ngọc.
04
Chọn File Firmware & Nạp
Kéo thả file miu_eilik.ino.bin vào khung Upload và bấm BẮT ĐẦU GHI FIRMWARE.
